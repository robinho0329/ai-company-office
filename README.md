# AI 회사 오피스 — 제조 데이터 분석팀 시각화

> **무엇이 진짜이고 무엇이 대본인지**
> · **진짜**: 기획 후보 3개와 그 근거 수치·파일 경로. 실제 리포트와 반복 평가 결과에서 뽑습니다.
> · **대본**: 직원 대사, 하루 진행, 각 부서의 상태 표시. 실행 중인 작업의 상태가 아닙니다.
> 실제 분석은 [mfg-anomaly-workflow](https://github.com/robinho0329/mfg-anomaly-workflow) 에서 돌아갑니다.

제조 공정 이상탐지 프로젝트의 **분석·보고 사규**(`AI_COMPANY.md`)를 눈에 보이게 만든
단일 HTML 페이지입니다. 부서 13개·직원 34명이 타일 격자 사무실을 걸어다니고,
기획부터 보고까지 16단계를 진행하며, **채택·승인 두 지점에서 멈춥니다.**

## 무엇을 보여주나

사규의 핵심은 "AI는 실행 직전까지만 준비하고, 결정은 사람이 한다"입니다.
이 페이지는 그 구조를 세 가지로 시각화합니다.

**① 두 가지 모드** — 회사가 오늘 무엇을 할지부터 정합니다.

- **모드 A · 신규 기획**: 보유 산출물을 훑어 아직 답하지 못한 질문을 후보 3개로 좁힙니다.
- **모드 B · 기존 디벨롭**: 직전 리포트가 스스로 "미측정·이관"이라 적은 항목을 개선 과제로 올립니다.

기획은 **과제발굴팀장이 주재하되 관점이 다른 팀장 3명이 함께** 앉습니다.
발굴팀 혼자면 "어느 파일에 있나"만 보게 되고, 관점 팀장만 모이면 각자 자기 팀 관심사로 기웁니다.

**② 사람이 멈추는 지점 2곳** — 입구(무엇을 시작할지)와 출구(무엇을 남길지)입니다.

- **★ 채택**: 후보 3개 중 1개를 고르거나 전부 반려. 고르기 전에는 채택 버튼이 잠깁니다.
- **★ 승인**: 검수 3팀장이 회의실에 앉고, 승인 / 수정 요청 / 보류 / 폐기를 누를 때까지 멈춥니다.
  수정 요청을 고르면 해석팀이 재작업한 뒤 다시 올라옵니다.

중간의 반려(피처 누수·불확실성 등)는 부서가 사규 기준으로 자율 처리합니다 —
반려 기준을 문서에 적어둔 이유가 사람을 부르지 않기 위해서입니다.

**③ 직원 상태 5종** — 완료(민트) / 진행 중(노랑) / 승인 대기(핑크) /
데이터 대기(라벤더) / 대기(흰색). **'데이터 대기'와 '대기'를 나눈 것이 핵심**으로,
둘 다 멈춰 있지만 전자는 앞 단계 산출물이 없어서고 후자는 순서를 기다리는 것입니다.
이걸 구분하지 않으면 "왜 막혔어?"에 답할 수 없습니다.

## 대표 지시창

화면 오른쪽에서 직접 물어볼 수 있습니다.

| 질문 | 답하는 사람 |
|---|---|
| 현황 보고 | 비서실장 |
| 왜 막혔어? | 비서실장 — 병목 1개만 짚습니다 |
| 이 수치 어디서 나왔어? | 재현성 팀장 — 산출 파일·해시·재현 커맨드 |
| 그 한계 근거 대봐 | 해석 팀장 — 결함모드별 재현율 원표 |
| 검수 소집 | 검수 3팀장이 회의실로 모입니다 |
| 후보 출처 | 과제발굴팀장 — 후보가 실측인지, 어느 파일에서 왔는지 |
| 모드 B로 | 다음 날 모드 예약 (하루 중간 전환은 거부합니다) |
| 집중 모드 | 라운지의 직원을 자리로 복귀시킵니다 |

부서명이나 직원 이름(예: "모델링팀 뭐해?", "최시온")으로도 물어볼 수 있습니다.

## 후보는 어디서 오나

기획 후보 3개는 **실제 산출물에서 뽑힙니다.** 화면에 출처 배지가 뜹니다.

| 배지 | 뜻 |
|---|---|
| 🟢 실측 | `candidates.json` 을 읽었다 — 후보에 인용 문장과 파일 경로가 붙는다 |
| 🟡 예시 | 파일을 못 읽어 내장 예시로 진행 중 |

`candidates.json` 은 분석 저장소의 `src/report/discover.py` 가 만듭니다.
리포트가 스스로 '미측정·미실행·이관'이라 적은 문장과, 반복 평가가 드러낸
완전 미탐 결함모드만 근거로 삼습니다 — **질문을 발명하지 않습니다.**

```bash
python -m src.report.discover        # 분석 저장소에서 실행
cp data/discovery/candidates.json ../ai-company-office/
```

## 실행

의존성이 없습니다. 다만 `candidates.json` 을 읽으려면 `fetch` 가 필요하고,
`file://` 로 직접 열면 브라우저가 이를 막아 예시 모드로 떨어집니다.

```bash
python -m http.server 8770
```

그다음 http://localhost:8770 을 엽니다. 파일을 그냥 열어도 동작하지만
후보는 내장 예시가 됩니다.

페이지를 열면 5초 후 자동 출근하고, 하루가 끝나면 15초 후 다음 날이 시작됩니다.
속도는 1x / 2x / 4x로 조절할 수 있으며, **배속은 시간에만 곱해지고 결과에는 영향을 주지 않습니다.**

## 구현 메모

- **렌더링**: 백킹스토어를 논리 크기의 2배 이상으로 잡아 슈퍼샘플링합니다.
  캔버스가 어떤 크기로 표시되든 확대가 아닌 축소가 일어나 계단현상이 없습니다.
  표시 배율이 0.55 미만이면 직원 이름을 생략합니다 — 읽히지도 않으면서 화면만 지저분해지기 때문입니다.
- **경로 탐색**: A* (4방향). 다른 직원이 서 있는 칸은 우회하고, 막히면 경로를 다시 계산합니다.
- **자율 행동 제한**: 대기 중인 직원은 라운지로 커피를 마시러 가지만,
  **회의 참석자와 근무 중 직원은 제외**됩니다. 이 규칙이 없으면 회의에 아무도 안 나타납니다.
- **루프**: `requestAnimationFrame`이 아니라 `setInterval`을 씁니다.
  rAF는 탭·패널이 화면에서 벗어나면 정지해 시뮬레이션까지 멈추기 때문입니다.
- **다음 날 전환**: `location.reload()` 대신 상태 리셋 — 임베드 환경에서 reload가 막힐 수 있습니다.
